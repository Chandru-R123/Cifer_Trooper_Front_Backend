  HOW THE FRONTEND CALLS THE BACKEND
  ───────────────────────────────────
  All HTTP calls go through a single thin wrapper at:
    src/lib/api.ts

  Base URL:
    const BASE_URL = "";        ← empty string = same origin
    Change this to a full URL (e.g. "https://api.cifertrooper.in") for
    cross-origin deployments or Cloudflare Workers environments.

  GET wrapper:
    fetch(`${BASE_URL}{path}`, { headers: { Accept: "application/json" } })
    Throws if response is not 2xx.

  POST wrapper:
    fetch(`${BASE_URL}{path}`, {
      method: "POST",
      headers: { "Content-Type": "application/json", Accept: "application/json" },
      body: JSON.stringify(payload),
    })
    Throws if response is not 2xx.

  Error handling:
    Every GET call has a .catch() that falls back to hardcoded default data.
    The frontend will NEVER crash if the API is down — it just shows defaults.
    Every POST call surface shows user-facing error text on failure.

  SECTION 4 — HTTP CONVENTIONS
================================================================================

  4.1  Status Codes Expected
    200 OK / 201 Created — Success
    400 Bad Request — Validation Error
    404 Not Found — Fallback to defaults
    500 Server Error — Fallback to defaults

  4.2  Required Response Headers
    Content-Type: application/json; charset=utf-8
    Access-Control-Allow-Origin: * (if separate domain)
